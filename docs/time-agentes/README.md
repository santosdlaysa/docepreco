# Como usar o time do DocePreço

O arquivo `AGENTS.md` na raiz orienta o Codex a carregar a base e o perfil adequado. São nove perfis reutilizáveis neste repositório: um coordenador e oito especialistas. Não são contas, GPTs separados ou processos executando continuamente. Nenhuma integração de envio, cobrança ou agendamento foi ativada por esta configuração.

## Pedidos prontos

As primeiras nove demandas estão em [DEMANDAS.md](DEMANDAS.md), com responsáveis, prioridades, entregas e critérios de conclusão. Para iniciar uma delas, peça: “Execute a DP-005”. As demandas cadastradas não executam automaticamente.

| Perfil | Exemplo de pedido |
| --- | --- |
| Coordenador | Time DocePreço: prepare uma campanha para quem se cadastrou e não criou a primeira receita. |
| Marketing | Marketing: planeje um teste de aquisição de assinantes com orçamento de R$ 100. |
| Conteúdo | Conteúdo: monte cinco posts educativos sobre precificação para esta semana. |
| Copy | Copy: escreva uma mensagem curta convidando a conhecer o Premium, sem emojis. |
| Atendimento | Atendimento: prepare uma resposta para esta dúvida de cliente: [mensagem]. |
| Comercial | Comercial: prepare uma abordagem para usuários Free que demonstraram interesse na loja online. |
| Suporte | Suporte: investigue este erro de acesso usando o relato e as evidências a seguir. |
| Financeiro | Financeiro: concilie estes extratos e mostre receitas, taxas e repasses do período. |
| Cobranças | Cobranças: prepare lembretes para estas assinaturas com vencimento confirmado. |

Use os nomes em linguagem natural; não precisa de comando especial. Quando houver várias áreas, o coordenador pode delegar a subagentes da sessão se a ferramenta estiver disponível, ou trabalhar em sequência. A entrega deve informar o que foi produzido, sem afirmar que mensagens foram enviadas quando são apenas rascunhos.

## Informações necessárias conforme a tarefa

Para campanhas, forneça objetivo, canal e oferta quando já definidos. Para textos de clientes, compartilhe apenas o contexto indispensável, omitindo senhas e dados sensíveis. Para finanças, forneça exportações do período ou autorize um acesso de leitura disponível. Para ofertas e cobranças, use os planos, links e status atuais.

Sem integração ou dados atuais, o agente pode preparar modelos e apontar o que falta. Os perfis não ganham acesso automático ao painel, WhatsApp, banco ou contas de pagamento.

## Manutenção

Ajuste `BASE.md` quando mudar o posicionamento ou as fontes de referência; ajuste o perfil quando mudar sua responsabilidade. Mantenha preços e métricas nas fontes atuais, evitando cópias que envelhecem. Materiais de clientes e extratos não devem ser adicionados ao Git.
